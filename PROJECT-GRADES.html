projects / grade management

c++ student grade management system

records, averages, and pass/fail status — my first taste of managing real data in C++.

c++consolevectorsrecords

the problem

Teachers juggle names, sections, and two semesters of grades per student. I wanted a console tool that collects everything and prints a clean report with averages and pass/fail status.

the approach

Parallel vectors (name, grade level, section, first- and second-semester grades, average, status) filled in an input loop; an average of 75 or above means PASS. A report pass at the end prints every record.

key features

  • any number of students per run
  • per-student record input with both semester grades
  • automatic average and pass/fail status
  • full report printed at the end

what i'd fix now

The original sizes its vectors with n before n is read from the user — undefined behavior that crashes on some machines (including mine, while recording demos for this site). Today I would read n first, or better, push_back a Student struct each iteration. That crash taught me more about declaration order and memory than any program that worked on the first try.
