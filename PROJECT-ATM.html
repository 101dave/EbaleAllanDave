c++ atm simulator

my first real C++ program — PIN authentication, deposits, withdrawals, and transaction history, all in the console.

c++consolecontrol flowvectors
$ g++ atm.cpp -o atm && ./atm
Enter yout card number: 123
Enter your pin: 123
Enter your choice: 2
Enter the amount: 500
<----------Transaction history---------->
Deposit amount: 500
New Balance: 600
<--------------------------------------->

real session, recorded from the compiled program

the problem

Model a real ATM in the console: verify the card before touching money, keep a running balance, and print a receipt-like history after every transaction.

the approach

A login loop that retries until the card number and PIN match, then a menu loop (balance / deposit / withdraw / exit). Vectors store every deposit and withdrawal so the history can be printed after each transaction.

key features

  • card + PIN verification with a retry loop
  • balance inquiry at any time
  • deposits and withdrawals with a running balance
  • transaction history printed after every operation
  • clean exit path

what i'd fix now

The login and menu loops use goto — a while loop with small functions would read much better. And the insufficient-funds check tests balance == -1 instead of balance < 0, so it only catches one exact overdraft. Finding those bugs myself was the real lesson: this project taught me to re-read my own code like a reviewer.
