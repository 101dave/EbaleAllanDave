scholog

an installable attendance web app for teachers — QR self check-in, offline sync, and daily PDF reports.

web apppwajavascriptsupabasepostgresqlvercel

Scholog teacher dashboard · attendance overview.

the problem

Taking attendance by hand eats class time: paper sheets get lost, summaries take hours, and students can't check their own records. I wanted something a teacher could open on any device and use in seconds — even on bad classroom wifi.

the approach

A static, installable PWA (no server to maintain) with Supabase Postgres behind per-account Row Level Security. Attendance is cached locally and synced automatically when the device is back online. The check-in scanner lives on its own page, so students never see the teacher dashboard — and don't even need an account: they scan a session QR or type their Student ID.

key features

  • class sections & student rosters
  • daily attendance (Present / Absent / Late / Excused) with a manual fallback — no QR session means “walang pasok”
  • daily PDF export with roster, statuses, and summary
  • QR check-in sessions with share link and full-screen projector mode
  • student camera scan or ID entry — no login needed
  • password reset flow and installable app (manifest, icons, offline cache)

what i learned

Designing for flaky connectivity (offline-first, sync later) changes every data decision you make. Row Level Security is a feature, not an afterthought. Keeping the scan flow separate from the dashboard kept both simple. And small rules like “no QR session = no class today” prevent whole categories of bad data.
